# Cinematic Portfolio Website

A modern multi-page portfolio website designed and developed by me to showcase my frontend development and UI/UX design skills.

The project focuses on:
- cinematic aesthetics
- glassmorphism
- responsive layouts
- clean typography
- smooth hover interactions
- modern portfolio structure

This portfolio is still actively evolving as I continue improving my frontend skills and adding new projects.

# Features

## Responsive Design
The website adapts across:
- desktop
- tablet
- mobile devices

using:
- Flexbox
- CSS Grid
- media queries

---

## Multi-Page Layout

The portfolio currently contains:

- Home Page
- About Page
- Projects Page

with navigation between pages.

---

## Glassmorphism UI

Several sections use:
- transparent layered backgrounds
- backdrop blur
- soft shadows
- hover animations

to create a modern glassmorphic aesthetic.

---

## Interactive Hover Effects

Cards and buttons feature:
- smooth transitions
- elevation animations
- shadow depth effects

to improve visual feedback and user experience.

---

## Cinematic Hero Sections

The homepage and internal pages use:
- layered gradients
- image blending
- dark overlays
- responsive hero layouts

to create a more immersive visual design.
